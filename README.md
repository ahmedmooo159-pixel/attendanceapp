# نظام الحضور والانصراف الذكي بالباركود - مركز المستقبل
### تطوير وبرمجة: م. أحمد مراد

---

## 🌟 نظرة عامة
تطبيق ويب متكامل، ذكي وفائق الدقة مخصص لـ **مركز المستقبل للخدمات التعليمية وخدمات كلية الحقوق** لتسجيل الحضور والانصراف بدقة متناهية بالثانية عبر مسح كود QR ثابت مع التعرف التلقائي على هاتف كل موظف، وتصدير شيتات إكسيل جاهزة للإدارة والشؤون المالية، وتصميم فخم ملائم لكبار السن.

---

## ✨ المميزات الرئيسية

### 1. واجهة الموظف (مسح وتوثيق ذاتي فائق السرعة):
- **كود QR موحد وثابت للمقر**: يتم طباعته وتعليقه في المقر ليمسحه الموظفون بهواتفهم الشخصية.
- **ربط الهاتف الذكي بالموظف**: عند فتح الرابط لأول مرة، يربط الموظف هاتفه باسمه لمرة واحدة فقط. وفي كل المرات التالية يتعرف النظام عليه فوراً.
- **المسح الأول في اليوم = تسجيل الحضور (Check-In)** مع حفظ التوقيت بالثانية بدقة.
- **المسح الثاني في نفس اليوم = تسجيل الانصراف (Check-Out)** وحساب عدد ساعات ودقائق وثواني العمل تلقائياً.
- **مؤقت حي للوردية**: يعرض للموظف عداداً مباشراً لعدد ساعات عمله منذ دخوله.
- **تنبيهات صوتية واهتزازات**: نغمات تأكيد فورية بدون أي تعقيد.

### 2. لوحة تحكم الإدارة (مصممة خصيصاً للمدير وكبار السن):
- **تصميم مريح للعين**: خطوط عربية كبيرة وواضحة (Cairo & Tajawal)، كروت تباين عالي، وتصنيفات ملونة سهلة.
- **إحصائيات لحظية**: عدد الحاضرين الآن، المنصرفين اليوم، الغائبين، وإجمالي ساعات العمل بالمركز.
- **سجل الحضور والانصراف المفصل**: عرض التاريخ، اسم الموظف، وقت الحضور، وقت الانصراف، مدة العمل، والحالة.
- **تصدير شيت إكسيل احترافي (.XLSX)** بضغطة زر واحدة:
  - **ورقة 1**: ملخص ساعات وأيام كل موظف وحساب الأيام ومتوسط الساعات.
  - **ورقة 2**: السجل اليومي الدقيق بجميع الثواني وتفاصيل الحضور والانصراف.
- **طباعة بوستر QR رسمي للمقر**: شيت A4 أنيق يحمل لوجو مركز المستقبل وكود المسح والتعليمات جاهز للطباعة فوراً.
- **إمكانية التعديل اليدوي**: في حال نسي موظف هاتفه، يمكن للمدير إضافة أو تعديل السجل يدوياً وتوثيقه.
- **حماية برمز مرور (PIN)**: افتراضياً `1234` لمنع دخول أي شخص غير مصرح له.
- **دعم الربط السحابي مع Firebase Firestore**: لمزامنة فورية بين جميع هواتف الموظفين وشاشة المدير في نفس اللحظة.
- **تنزيل واستعادة نسخ احتياطية (JSON)** بضغطة زر لضمان عدم ضياع أي بيانات مالية.

## 🚀 طريقة الرفع على GitHub و Vercel

### الخطوة 1: الرفع على GitHub
```bash
git init
git add .
git commit -m "Initial commit - Al-Mustaqbal Attendance System by Ahmed Mourad"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/almustaqbal-atten.git
git push -u origin main
```

### الخطوة 2: النشر على Vercel (مجاناً بضغطة واحدة)
1. افتح موقع [Vercel.com](https://vercel.com) وسجل الدخول بحساب GitHub.
2. اضغط **Add New Project** واختر المستودع `almustaqbal-atten`.
3. اضغط **Deploy** مباشرة (المشروع جاهز كـ Static Web App ولا يحتاج أي Build Command).
4. ستحصل على رابط فوري مثل `https://almustaqbal-atten.vercel.app`.

## 📌 طباعة كود المقر:
1. ادخل إلى **لوحة تحكم الإدارة** (رمز المرور: `1234`).
2. افتح تبويب **كود QR المقر الموحد (طباعة)**.
3. اضغط **طباعة هذه اللوحة لتعليقها في المقر**، وقم بتعليق الورقة عند مدخل المركز!
