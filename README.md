# نظام الحضور والانصراف الذكي بالباركود — مركز المستقبل
### تطوير وبرمجة: م. أحمد مراد

---

## 🌟 نظرة عامة
تطبيق ويب متكامل، ذكي وفائق الدقة مخصص لـ **مركز المستقبل للخدمات التعليمية وخدمات كلية الحقوق** لتسجيل الحضور والانصراف بدقة متناهية بالثانية عبر مسح كود QR ثابت مع التعرف التلقائي على هاتف كل موظف، وتصدير شيتات إكسيل جاهزة للإدارة والشؤون المالية، وتصميم فخم ملائم لكبار السن.

---

## ✨ المميزات الرئيسية

### 1. واجهة الموظف (مسح وتوثيق ذاتي فائق السرعة)
- **كود QR موحد وثابت للمقر**: يُطبع ويُعلق في المقر ليمسحه الموظفون بهواتفهم الشخصية.
- **ربط الهاتف الذكي بالموظف**: عند فتح الرابط لأول مرة، يربط الموظف هاتفه باسمه لمرة واحدة. في كل المرات التالية يتعرف النظام عليه فوراً.
- **المسح الأول في اليوم = تسجيل الحضور (Check-In)** مع حفظ التوقيت بالثانية.
- **المسح الثاني في نفس اليوم = تسجيل الانصراف (Check-Out)** وحساب مدة العمل تلقائياً.
- **مؤقت حي للوردية**: عداد مباشر لعدد ساعات العمل منذ الحضور، يظل مرئياً حتى بعد منتصف الليل لورديات الليل.
- **دعم الورديات الليلية**: يتعرف النظام على الوردية المفتوحة من اليوم السابق ويتيح الانصراف منها بعد منتصف الليل طالما لم تتجاوز `MAX_SHIFT_HOURS`.
- **تنبيهات صوتية واهتزازات**: نغمات تأكيد فورية.

### 2. لوحة تحكم الإدارة (مصممة خصيصاً للمدير)
- **تصميم مريح للعين**: خطوط عربية كبيرة (Cairo & Tajawal)، كروت تباين عالي.
- **إحصائيات لحظية**: عدد الحاضرين الآن، المنصرفين، الغائبين، وإجمالي ساعات العمل.
- **شارة "نسي الانصراف"**: تظهر فقط على السجلات المفتوحة التي تجاوزت مدتها `MAX_SHIFT_HOURS` (لا تُغلق تلقائياً).
- **سجل الحضور المفصل**: التاريخ، الاسم، وقتي الحضور والانصراف، مدة العمل، الحالة.
- **تصدير شيت إكسيل (.XLSX)** بضغطة واحدة:
  - ورقة 1: ملخص ساعات وأيام كل موظف.
  - ورقة 2: السجل اليومي الدقيق بجميع التفاصيل.
- **طباعة بوستر QR رسمي**: شيت A4 جاهز للطباعة والتعليق.
- **تعديل يدوي**: يستطيع المدير إضافة أو تعديل السجلات يدوياً.
- **حماية برمز مرور (PIN)**: افتراضياً `1234`.
- **نسخ احتياطية JSON**: تصدير واستيراد آمن مع دمج ذكي (يُراجع القسم أدناه).

## 🔄 نظام استيراد النسخ الاحتياطية (JSON Import — F12)

الاستيراد **يضيف ولا يحذف أبداً** — يتحقق لكل سجل:

| الحالة | السلوك |
|---|---|
| معرّف جديد | يُضاف مباشرة |
| معرّف موجود + الملف المستورد أحدث (`updatedAt`) | يُحدَّث (مع حماية الحقول المحظورة) |
| معرّف موجود + الملف المستورد أقدم أو مساوٍ | يُتجاهل |

**الحقول المحظورة** التي لا يمكن للاستيراد الكتابة فوقها أبداً:
- `deviceToken` (الموظفون والسجلات)
- `allowDirectButton` (الموظفون فقط)

بعد الاستيراد يظهر إشعار: `"الاستيراد مكتمل — X جديد، Y محدَّث، Z تجاهل (من N سجل)"`

## ⚙️ ثوابت وإعدادات النظام

| الثابت | القيمة | الوصف |
|---|---|---|
| `DEFAULT_ADMIN_PIN` | `'1234'` | رمز المرور الافتراضي للإدارة |
| `STATION_SECRET_TOKEN` | `'MSTQ_HQ_OFFICE_2026'` | الرمز السري المدمج في QR المقر |
| `MIN_SECONDS_BEFORE_CHECKOUT` | `120` | الحد الأدنى بالثواني بين الحضور والانصراف (2 دقيقة) لمنع الضغط المزدوج |
| `MAX_SHIFT_HOURS` | `12` | الحد الأقصى لساعات الوردية الواحدة. يتيح انصراف ورديات الليل بعد منتصف الليل طالما لم تمر 12 ساعة على الحضور. السجلات المفتوحة الأقدم من 12 ساعة تُميَّز بشارة "نسي الانصراف" ولا تُغلق تلقائياً. |
| `REQUIRE_TOKEN` | `true` | اشتراط توكن المحطة للتحقق من QR المقر المطبوع |
| `UNDO_WINDOW_SECONDS` | `600` | مهلة التراجع الذاتي للموظف (10 دقائق) عن تسجيل الحضور أو الانصراف الخاطئ |
| `CACHE_NAME` (SW) | `'almustaqbal-v2'` | اسم كاش Service Worker الحالي |

## 🛠️ المساعدات والدوال الرئيسية

### `js/time-utils.js` (مشترك بين app.js و excel-export.js)

| الدالة | الوصف |
|---|---|
| `cairoDate(d?)` | تُعيد التاريخ بتوقيت القاهرة بصيغة `YYYY-MM-DD` |
| `cairoOffsetMs(d?)` | تُعيد فارق توقيت القاهرة عن UTC بالميلي‑ثانية (آمن من التغييرات الصيفية DST) |
| `cairoTimeToDate(dateStr, timeStr)` | تحويل تاريخ + وقت بتوقيت القاهرة إلى `Date` UTC صحيح (خوارزمية Two-Pass) |
| `getCairoTimeInputVal(isoStr)` | تُعيد الوقت بصيغة `HH:MM:SS` بتوقيت القاهرة من ISO string |

### دوال رئيسية في `js/app.js`

| الدالة | الوصف |
|---|---|
| `getActiveRecord(empId)` | تُعيد السجل النشط للموظف: سجل اليوم إن وُجد، أو آخر سجل مفتوح من يوم سابق ضمن `MAX_SHIFT_HOURS` |
| `normalizeNameKey(name)` | تُوحّد الاسم للمقارنة: يحذف التشكيل والتطويل، يحوّل أ/إ/آ←ا، ة←ه، ى←ي |
| `generateNextEmployeeCode()` | يُنشئ الرمز الوظيفي التالي بصيغة `EMP-XX` بناءً على أعلى رقم موجود |
| `importJsonBackup(fileInput)` | استيراد آمن مع التحقق من الـ Schema والدمج الذكي (newer-wins) |
| `exportJsonBackup()` | تصدير نسخة احتياطية كاملة بتنسيق JSON |

## 🔧 Service Worker — almustaqbal-v2

| النوع | الاستراتيجية |
|---|---|
| HTML / JS / CSS (نفس الأصل) | **Network-first** — يُحضر من الشبكة دائماً، ويسقط على الكاش عند انقطاع الإنترنت |
| صور وخطوط (images/fonts) | **Stale-while-revalidate** — يُجيب من الكاش فوراً ويُحدّث في الخلفية |
| حزم CDN الخارجية | تُكاش مسبقاً عند التثبيت بـ `Promise.allSettled` (لا يُوقف التثبيت عند الفشل) |
| Firebase Realtime / Firestore streaming | **يُتجاهل** ولا يمر عبر Service Worker |

عند تحديث التطبيق يظهر إشعار: **"تم تحديث التطبيق — يرجى إعادة تحميل الصفحة 🔄"**

> **ملاحظة Vercel:** `vercel.json` يُضيف `Cache-Control: no-cache` لملف `/sw.js` لضمان أن المتصفح يجلب أحدث نسخة دائماً.

## 🚀 طريقة الرفع على GitHub و Vercel

### الخطوة 1: الرفع على GitHub
```bash
git init
git add .
git commit -m "Initial commit - Al-Mustaqbal Attendance System by Ahmed Mourad"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/almustaqbal-atten.git
git push -u origin main
```

### الخطوة 2: النشر على Vercel (مجاناً بضغطة واحدة)
1. افتح [Vercel.com](https://vercel.com) وسجل الدخول بحساب GitHub.
2. اضغط **Add New Project** واختر المستودع `almustaqbal-atten`.
3. اضغط **Deploy** مباشرة (Static Web App — لا يحتاج Build Command).
4. ستحصل على رابط مثل `https://almustaqbal-atten.vercel.app`.

## 📌 طباعة كود المقر
1. ادخل إلى **لوحة تحكم الإدارة** (رمز المرور: `1234`).
2. افتح تبويب **كود QR المقر الموحد (طباعة)**.
3. اضغط **طباعة هذه اللوحة لتعليقها في المقر** وضعها عند مدخل المركز.
